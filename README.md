# 小深唤醒（Wake Assistant）

喊一句「小深」就把手机变成语音助手：**唤醒词 → 说一句话 → 本机转写 → DeepSeek 回答 → 读出来**。

- 唤醒词检测：Porcupine（离线，低功耗，个人免费）
- 语音转文字：Vosk 中文小模型（离线，第一次下载约 42 MB）
- 回答：DeepSeek `deepseek-flash`
- 朗读：手机自带 TTS（离线）

只有「回答」这一步联网计费，其余全在本机。

## 你需要准备的三样东西

1. **Picovoice AccessKey**：到 https://console.picovoice.ai 注册免费账号（Personal 计划），
   首页就能看到 AccessKey。
2. **唤醒词文件 `.ppn`**：同一个控制台 → Porcupine → 新建关键词，
   语言选 **Chinese（普通话）**，关键词填 `小深`，训练完下载 `.ppn`。
3. **DeepSeek API Key**：https://platform.deepseek.com 里创建。

三样都填进 App 后点「开始常驻监听」即可。

## 编译（不用电脑）

1. 在手机上把整个 `wake-assistant` 目录上传到 GitHub（新建仓库，直接拖文件或用网页上传）。
2. 仓库的 **Actions** 页会自动跑 `build-apk`，约 5 分钟。
3. 打开跑完的那次 → 底部 **Artifacts** → 下载 `wake-assistant-debug.zip` → 解压得到 APK → 安装。

有电脑的话，Android Studio 直接打开这个目录也能编译。

> 我没法在手机上编译（这里没有 JDK 和 Android SDK），所以第一次构建如果报错，
> 把 Actions 的红色日志发我，我照着改。

## 使用

1. 打开 App，填 AccessKey、DeepSeek Key。
2. 点「选择唤醒词文件」，选下载好的 `.ppn`。
3. 点「开始常驻监听」，允许麦克风权限。
4. 锁屏也能用（通知栏会常驻一条「正在聆听」）。

## 华为手机必须做的事

DVC-AN20 这类机型的省电策略会杀掉后台服务：

- 设置 → 电池 → 应用启动管理 → 找到「小深唤醒」→ 手动管理，三个开关全开；
- 设置 → 电池 → 更多电池设置 → 关闭「休眠时始终保持网络连接」不影响，但要允许后台活动；
- 如果过一阵又没反应，打开 App 看通知还在不在，不在就重新点「开始」。

## 已知局限

- 唤醒词识别质量取决于 Porcupine 训练的关键词，环境吵时要靠近点说。
- 回答时麦克风还在听，纯粹为了「你一开口就停」；如果你让它念出「小深」两个字，可能自触发一次。
- 常驻监听会多耗电，大概每天 5–10%，长期不用就在通知栏点「停止」。
- 现在只做问答，还不能帮你去操作手机或调 DSH 的工具；要这些得再往后接。
